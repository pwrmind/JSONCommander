# 📁 JSON Commander

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![Alpine.js](https://img.shields.io/badge/Alpine.js-8BC0D0?style=for-the-badge&logo=alpine.js&logoColor=white)](https://alpinejs.dev/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)

**Total JSON Commander** — это легковесный двухпанельный менеджер JSON-данных, работающий прямо в браузере. Вдохновленный классическими файловыми менеджерами (такими как Total Commander и Norton Commander), этот инструмент позволяет визуально перемещать, копировать, редактировать и сравнивать ветки JSON без необходимости писать сложные скрипты или использовать тяжелые IDE.

## ✨ Особенности

*   **Две независимые панели**: Удобное сравнение двух JSON-файлов бок о бок.
*   **Навигация как в файловой системе**: Объекты `{}` и массивы `[]` отображаются как папки, а примитивы — как файлы.
*   **Управление с клавиатуры**: Полностью клавиатуро-ориентированный интерфейс (F-клавиши, стрелки, Tab).
*   **Умное копирование (F5)**: Безопасное глубокое клонирование данных между панелями с обходом ошибок Proxy-объектов Alpine.js.
*   **Создание узлов (F7)**: Возможность добавлять новые ключи, объекты, массивы и примитивы с выбором типа данных.
*   **Редактирование (F2)**: Изменение значений прямо в строке с сохранением исходного типа данных.
*   **Живой поиск**: Фильтрация ключей в реальном времени.
*   **Импорт и экспорт**: Загрузка локальных `.json` файлов и сохранение результата на диск.
*   **Zero Dependencies**: Весь код в одном HTML-файле. Никаких сборщиков, `node_modules` или серверов.

## 🚀 Как запустить

Приложению не требуется установка или сборка.

1. Склонируйте репозиторий или просто скачайте файл `index.html`.
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Safari, Edge).
3. Наслаждайтесь работой!

*(Также вы можете запустить его через GitHub Pages, просто включив эту опцию в настройках репозитория).*

## ⌨️ Горячие клавиши

| Клавиша | Действие |
| :--- | :--- |
| `Tab` | Переключить активную панель (влево/вправо) |
| `↑` / `↓` | Перемещение курсора по списку |
| `Enter` | Войти в объект/массив или применить изменение |
| `Backspace` | Выйти на уровень выше (к родительскому узлу) |
| `F2` | Редактировать выбранный узел |
| `F5` | Скопировать выбранный узел в противоположную панель |
| `F7` | Создать новый элемент (ключ/объект/массив) |
| `F8` | Удалить выбранный узел |
| `Esc` | Отменить редактирование или закрыть модальное окно |

## 🛠️ Технические детали

*   **Стек**: Чистый HTML, CSS (Tailwind CSS через CDN) и JavaScript (Alpine.js через CDN).
*   **Обход Proxy**: Alpine.js оборачивает данные в реактивные Proxy. Для безопасного копирования в коде используется `JSON.parse(JSON.stringify(value))`, чтобы избежать ошибок клонирования.
*   **Виртуальный DOM**: Список элементов рендерится реактивно с помощью директивы `x-for`.
*   **Файловый ввод-вывод**: Используется `FileReader` для чтения файлов и `Blob` для их сохранения.
